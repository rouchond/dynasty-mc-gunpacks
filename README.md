# Dynasty MC downloads

Current modpack version: **1.1** (Minecraft 1.21.1 / NeoForge).

## [Download Dynasty MC 1.1](https://github.com/rouchond/dynasty-mc-gunpacks/releases/tag/v1.1)

Download **Dynasty.MC.1.1.mrpack** from the release Assets and import it into Modrinth App as a new profile. It includes the mods, configs, KubeJS scripts, and five TacZ gunpacks. No separate gunpack download is needed.

If you already use an older Dynasty MC profile, install 1.1 as a new profile and select it when joining the server. Your existing profile remains available. The Modrinth shared instance may not yet contain every file in this release.

[Release notes and SHA-256](https://github.com/rouchond/dynasty-mc-gunpacks/releases/tag/v1.1) list the changes and archive hash. Original assets belong to their respective creators. This is an unofficial modpack distribution, with no author endorsement implied.
