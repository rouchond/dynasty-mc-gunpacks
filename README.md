# Dynasty MC gunpacks

Companion gunpacks for the Dynasty MC Modrinth shared instance.

## Download status

The repository is ready. The September 27 bundle is prepared locally, but a public download has not been published while redistribution permissions are checked for the converted and patched packs.

## Installation when a release is available

1. Close Minecraft.
2. Download the gunpack bundle from this repository’s Releases page.
3. Open your Dynasty MC instance folder in Modrinth.
4. Extract the outer bundle there. The five gunpack ZIP files belong directly inside `tacz/`. Leave those five ZIP files compressed.
5. Move older copies of these same packs outside `tacz/` to prevent duplicate namespaces. Keep unrelated packs and `tacz_default_gun`.
6. Launch Minecraft.

Mods, configs and KubeJS recipes are updated through the Modrinth shared instance. These gunpacks are a separate download when their version changes.
