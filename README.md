# Dynasty MC downloads

Current modpack version: **1.0.7** (Minecraft 1.21.1 / NeoForge).

## [Download the latest release](https://github.com/rouchond/dynasty-mc-gunpacks/releases/latest)

### New installation

Download **Dynasty MC 1.0.7.mrpack** from the release Assets, then import it into Modrinth App. It includes mods, configs, KubeJS scripts and the five gunpacks. You do not need the separate gunpack ZIP.

### Already using the Modrinth shared instance

Accept the latest shared mod/config update. For gunpacks, download **Dynasty-Gunpacks-2026-09-27.zip** from the release Assets.

1. Close Minecraft and open your Dynasty MC instance folder in Modrinth.
2. Extract the outer bundle there: five gunpack ZIP files go directly inside `tacz/`. Keep the inner ZIP files compressed.
3. Move older copies of these same packs outside `tacz/` to avoid duplicate namespaces. Keep unrelated packs and `tacz_default_gun`.
4. Launch Minecraft.

Download gunpacks again only when their bundle changes. Mods, configs and KubeJS scripts can be updated through the shared instance.
