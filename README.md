# Dynasty MC downloads

Current modpack version: **1.11** (Minecraft 1.21.1 / NeoForge).

## [Download Dynasty MC 1.11](https://github.com/rouchond/dynasty-mc-gunpacks/releases/tag/v1.11)

Download **Dynasty.MC.1.11.mrpack** from the release Assets and import it into Modrinth App as a new profile. It includes the mods, configs, KubeJS scripts, and five TacZ gunpacks. No separate gunpack download is needed.

Version 1.11 expands Nexus supplies and adds inventory value tooltips. [Patch sources and supply rules](patches/nexus-supplies-1.11) are included in this repository. Multiplayer Nexus behavior requires the matching settlement companion on the server. In-game acceptance remains pending.

If you already use an older Dynasty MC profile, import 1.11 as a new profile and keep your existing profile available. The Modrinth shared instance may not yet contain every file in this release.
